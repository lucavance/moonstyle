# MoonStyle 0.3.0

MoonStyle 0.3.0 moves the ordinary project workflow to native MoonBit tooling. Authoring, CSS extraction, property generation, builds, file watching, the development HTTP server and default validation work without installing Node, Bun or Vite.

### Native project workflow

- Install the CLI from the reviewed source with `moon install ./tooling/native/src/cmd/moonstyle`.
- Use `moonstyle init`, `generate`, `check`, `doctor --strict`, `watch`, `build` and `dev`.
- Build browser applications through Moon's JavaScript backend, with binary assets copied from `public/`.
- Inspect applied styles using the MoonBit browser client and CSS source maps. Development retains the last successful site after errors and reloads after recovery. Production output excludes the inspector and development maps.

### Migration from 0.2.0 tooling

The JavaScript CLI and root Node package have been removed. Install the native CLI from the same source revision as the library. Existing project metadata can be reviewed with `moonstyle upgrade --dry-run`, then migrated with `moonstyle upgrade`. Schema-v1 Vite and entry files remain user-owned and are preserved.

The optional Vite adapter is a private source package under `tooling/vite/` that delegates to the installed CLI. Node dependencies for standards, the StyleX oracle and browser verification are installed independently; they are outside the default workflow.

### Library compatibility and validation

The public library interfaces match the 0.2.0 baseline. The reviewed surface remains 392 typed CSS properties, artifact schema v14, property API schema v18 and the pinned StyleX 0.19.1 application-order contract.

Validation covers native, Wasm, Wasm GC and JavaScript execution; 63 rejected authoring programs; installed CLI and independent Git consumers; StyleX comparisons; Chromium, Firefox and WebKit; dependency licenses and security; reproducible generation; and native/development performance budgets.

Use `moon run tools/validate.mbtx` for native validation and `moon run tools/validate-ci.mbtx` for the complete release checks. See the repository documentation for the pinned compiler/core and optional extended dependencies.

The release source passed both [hosted CI jobs](https://github.com/lucavance/moonstyle/actions/runs/41834468381). The published `lampclaw/moonstyle@0.3.0` module was also checked in an independent registry consumer without a workspace source override.
